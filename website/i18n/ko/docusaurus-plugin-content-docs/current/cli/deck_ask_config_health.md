## deck ask config health

내장 ask 증강(augmentation) 제공자 상태를 점검합니다

```
deck ask config health [flags]
```

### 옵션

```
  -h, --help   help for health
```

### 상위 명령에서 상속된 옵션

```
      --log-format string   diagnostic log format (text|json) (default "text")
      --v int               diagnostic verbosity level (0-3; higher is more detailed)
```

### 관련 항목

* [deck ask config](deck_ask_config.md)	 - 전역 ask config 기본값과 API 자격 증명을 관리합니다
