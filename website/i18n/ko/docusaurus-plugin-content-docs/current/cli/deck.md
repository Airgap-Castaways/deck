## deck

deck

### 개요

오프라인 준비 및 로컬 실행을 위한 deck 워크플로를 실행합니다.

### 옵션

```
  -h, --help                help for deck
      --log-format string   diagnostic log format (text|json) (default "text")
      --v int               diagnostic verbosity level (0-3; higher is more detailed)
```
